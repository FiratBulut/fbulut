# Assetlieferung – Vorlage

Produzent speichert diesen Beleg als `lieferung.md` neben seinen tatsächlichen Ergebnisdateien.
Opus-PM trägt die Annahme in den einzelnen Assetauftrag ein; dieser Beleg ist keine Aufgabenliste.
Es gilt der [Teamworkflow](../TEAM_WORKFLOW.md). Keine leeren Vorlagen als fertiges Ergebnis melden.

- Asset-ID / Stufe / Lieferrevision / Datum / Produzent und Sitzung:
- Verwendeter Auftrag: Pfad, Revision und SHA-256 des eingefrorenen Eingabestands:
- Weitere verwendete Eingaben: tatsächliche Dateipfade und SHA-256:
- Ausgeführte Arbeit / tatsächlich verwendetes Werkzeug und verfügbare Version:
- Ergebnisdateien: eindeutiger Pfad, Dateiformat, Größe in Bytes und SHA-256 je benötigter Datei:
- Tatsächlich geprüft: Prüfung, Ergebnis und Belegpfad:
- Abweichungen / Annahmen / nicht geprüft / möglicher Korrekturbedarf:
- Transfer: vereinbarter Zielordner erreicht oder konkrete noch zu übertragende Datei:
- Nächste mögliche Handlung für Opus-PM:

Nur passende Angaben ergänzen:

| Lieferung | Nötiger Nachweis |
| --- | --- |
| Codex-Bild | Tatsächliche Pixelmaße, Öffnen erfolgreich, bei geforderter Transparenz tatsächlicher Alphakanal; Referenz-/Eingabestand. |
| Blender-Modell | Erneut geöffnet, Maße/Einheit, Objektliste/Pivot, Ansichten; Annahmen zu nicht sichtbaren Seiten. |
| Material/Export | UV-/Material-/Texturbezug, benötigte Kollision/Detailstufen, Exportoptionen; separat importierter Export mit Maß-/Materialprüfung. |
| Integration | Skripte und erwarteter Projektstand, Zielpfade, Wiederherstellungsweg; vorbereitet vs. tatsächlich ausgeführt getrennt. |
| Technische Vorprüfung (Opus 5) | Tatsächliche Dateien, durchgeführte Kontrollen und vollständige Belege; keine Behauptung einer Fable-Endabnahme. |
| Endprüfung (Fable, erst nach kompletter Umsetzung) | Eingefrorenes Gesamtpaket, selbst gesehene Referenz-/Ergebnisbilder, Kriterien und einmaliges Urteil: bestanden/Korrektur nötig/nicht beurteilbar. |

Eine Prüfsumme identifiziert eine Datei, beweist aber keine Qualität. Ein vorhandenes Bild
beweist kein fertiges Modell; ein fertiges Modell keinen erfolgreichen Unreal-Import.
Ungeprüfte Punkte ausdrücklich offen lassen; keine erwarteten Resultate als Messung ausgeben.
